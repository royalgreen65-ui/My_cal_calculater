# Professional Calorie & TDEE Calculator

A clean, modern, and responsive Calorie Calculator built with vanilla JavaScript, CSS3, and HTML5. This tool calculates Basal Metabolic Rate (BMR) and Total Daily Energy Expenditure (TDEE) using the industry-standard Mifflin-St Jeor Equation.

## ✨ Features
- **Accurate Calculations**: Uses the Mifflin-St Jeor Equation for high precision.
- **Dual Unit Support**: Seamlessly switch between Imperial (lbs, ft/in) and Metric (kg, cm) systems.
- **Dynamic Results**: Instantly see BMR, TDEE, and specific calorie targets for weight loss or gain.
- **Safety Minded**: Includes logic to flag calorie targets that fall below recommended daily minimums.
- **Mobile-First Design**: Fully responsive UI that works on desktops, tablets, and smartphones.
- **Zero Dependencies**: Built with pure Vanilla JS — no heavy frameworks, ensuring fast load times.

## 🛠️ Technical Implementation
- **Architecture**: Separated concerns (HTML for structure, CSS for presentation, JS for logic).
- **Accessibility**: ARIA labels and semantic HTML for screen-reader compatibility.
- **Validation**: Real-time input validation and user-friendly error messaging.
- **UX**: Smooth scrolling to results and interactive segmented controls.
